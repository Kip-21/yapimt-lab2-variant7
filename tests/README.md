# Проверка сборки и работы программы

Все результаты получены запуском настоящего `code/lab2.exe` в консолях Windows.
Проверяющий скрипт не реализует программу вместо ассемблерного кода: он передаёт
ввод, читает вывод, сравнивает его с ожидаемым и проверяет код завершения.

## Что приложено

- `../code/main.asm` — исходный файл MASM, включённый также в листинг отчёта.
- `../code/lab2.exe` — проверенный исполняемый файл x86.
- `build.log` — вывод реальной сборки с командами, кодом завершения и SHA-256.
- `run_tests.py` — скрипт проверки 15 случаев, только стандартная библиотека Python 3.
- `run-info.json` — время проверки UTC, команда запуска и SHA-256 исходника и EXE.
- `results.json` — введённые строки, ожидаемые и фактические результаты, коды выхода.
- `console-01.txt` … `console-15.txt` — текст, прочитанный из буфера каждой консоли.
- `../code/tests.txt` — общий читаемый протокол всех проверок.
- `screenshots/11-russian.png`, `screenshots/14-too-long.png` — снимки настоящих
  окон консоли: русский ввод и отклонение 256 символов. Изображения сохранены
  функцией Windows `PrintWindow`; текст и оформление на них не дорисовывались.

В `expected` и `actual` записывается результат без метки `Palindrome:` и перевода
строки; для ошибочных случаев — полное сообщение `Error: ...`.
В этих значениях пробелы сохраняются. В текстовом протоколе консоли конечные
пробелы строк не показаны, длинные строки перенесены по ширине окна.

## Как повторить

Из корня репозитория в PowerShell сначала соберите программу:

```powershell
.\code\build.bat
```

Затем выполните один из вариантов:

```powershell
py -3 .\tests\run_tests.py
py -3 .\tests\run_tests.py --screenshots
```

Второй вариант дополнительно сохраняет снимки окон тестов № 11 и № 14;
во время захвата эти два окна ненадолго становятся видимыми.
Скрипт сообщает `PASS: 15/15 console tests` только после успешных проверок.
При расхождении выполнение прерывается с ошибкой.

Чтобы сохранить новый журнал сборки, вместо обычной команды сборки выполните:

```powershell
.\code\build.bat 2>&1 | Tee-Object -FilePath .\tests\build.log
```

Для запуска основной программы Python не нужен; он используется только
для автоматической проверки. Проверку и получение снимков следует выполнять
в Windows с доступным рабочим столом.
