# ЯПиМТ — лабораторная работа № 2, вариант 7

Цепочечные команды. MASM, Win32.

Программа формирует палиндром: дописывает исходную строку в обратном порядке.
Например, `abcd` → `abcddcba`, `aba` → `abaaba`. Используются
`REP MOVSB`, `LODSB` и `STOSB`. Пробелы, регистр и знаки препинания сохраняются.

## Быстрый запуск

1. Скачайте репозиторий и распакуйте архив.
2. Откройте `code/run.bat`.
3. Введите строку и нажмите Enter. Результат появится после `Palindrome:`.

Для готового EXE дополнительные библиотеки не нужны. Для пересборки запустите
`code/build.bat`: нужна Visual Studio или Build Tools с компонентом
«Разработка классических приложений на C++» и Windows SDK.

Допустимо от 0 до 255 символов в CP866, включая русские буквы. Результат
содержит вдвое больше символов. Ввод длиннее 255 символов отклоняется.
Запускайте программу в консоли Windows без перенаправления ввода/вывода.

## Сборка отчёта

Код и отчёт находятся в отдельных папках. Из папки `report` выполните два раза:

```bat
xelatex -interaction=nonstopmode -halt-on-error report.tex
```

Нужен XeLaTeX (MiKTeX или TeX Live), шрифты Times New Roman и Consolas.
Сохраняйте папки `code`, `report` и `tests` рядом: листинг берётся из
`code/main.asm`, а настоящие снимки консоли — из `tests/screenshots/`.
Все 15 тестов перечислены в отчёте; для двух приведены назначение, ожидание
и скриншот. Сохранены также текстовые протоколы всех запусков.
Титульного листа нет; его можно добавить отдельно.
