# Сборка, запуск и отладка

## Запуск готовой программы

1. Откройте папку `code` и дважды щёлкните `run.bat`.
2. После `Enter a string (max 255 characters):` введите строку и нажмите Enter.
3. После `Palindrome:` появится результат. Нажмите любую клавишу, чтобы закрыть окно.

Например:

```text
Enter a string (max 255 characters): abcd
Palindrome: abcddcba
```

Допустима пустая строка. Пробелы, регистр букв и знаки препинания сохраняются.
Максимум — 255 символов; результат содержит вдвое больше символов.
Программа работает с однобайтовой кодировкой CP866, включая русские буквы.
Символы вне этой кодировки, например эмодзи, не поддерживаются.
Ввод и вывод выполняются через консольные функции из методички, поэтому запускайте
программу в обычной консоли Windows, без перенаправления через `<`, `>` или конвейер.

## Сборка из исходника

Нужна Visual Studio либо Visual Studio Build Tools с компонентом
«Разработка классических приложений на C++» (Desktop development with C++),
включающим средства MSVC x86/x64 и Windows SDK.

Запустите `code/build.bat`. Скрипт найдёт Visual Studio, подключит инструменты x86
и создаст `lab2.exe`. После изменения `main.asm` сначала повторите сборку,
затем запустите `run.bat`.

Из PowerShell, находясь в папке `code`:

```powershell
.\build.bat
.\run.bat
```

При сборке вручную откройте **x86 Native Tools Command Prompt for VS**, перейдите
в папку `code` и выполните:

```bat
ml /nologo /c /coff /Zi main.asm
link /nologo /subsystem:console /machine:x86 /debug /out:lab2.exe main.obj kernel32.lib
lab2.exe
```

Для отладки можно открыть `lab2.exe` в Visual Studio, открыть `main.asm`, поставить
точку останова на `CLD` перед `REP MOVSB` и запустить отладку. Файлы `main.obj`
и `lab2.pdb` создаются при сборке и содержат отладочную информацию.
